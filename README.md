## 主な比較ポイント

### 収入保障保険

| 項目 | プルデンシャル | ソニー（Ⅱ型） | 三菱電機（いのち） |
|------|:------------:|:------------:|:---------------:|
| 年金月額 | 15万円 | 10万円 | 一括500〜2,000万円 |
| 月額保険料 | 3,423円 | 5,420円 | 675〜1,350円 |
| 障害・介護保障 | ❌ | ✅ | ❌ |
| 高度障害加算 | ✅ +7.5万円 | ❌ | ❌ |
| 保障期間 | 65歳まで | 65歳まで | 1年更新 |

### 併用プラン分析

- **ソニーⅠ型 + 三菱電機**：死亡保障は厚いが障害・介護が弱い
- **推奨**：ソニーⅡ型 + 三菱電機補完（月額約6,400円）でバランス重視
