# ソニー生命 無解約返戻金型収入保障保険 提案内容

## 基本情報

| 項目 | 内容 |
|------|------|
| **商品名** | 無解約返戻金型収入保障保険（Ⅱ型） |
| **被保険者** | 佐野様（1984年10月21日生・40歳・男性） |
| **契約日** | 2025年6月23日 |
| **払込期間** | 65歳満了 |
| **保険期間** | 65歳満了（約25年間） |
| **最低支払保証期間** | 2年 |
| **適用割引** | 優良体・非喫煙者割引特則 |

## 保障内容

| 保障項目 | 金額 |
|---------|------|
| **年金月額（死亡時）** | 10万円 |
| **年金月額（高度障害時）** | 10万円 |
| **リビング・ニーズ特約** | 付帯 |

### 死亡時の受取総額（残存期間による）

| 万一の時期 | 年齢 | 残り期間 | 受取総額 |
|-----------|-----|---------|---------|
| 契約直後 | 40歳 | 25年 | **3,000万円** |
| 5年後 | 45歳 | 20年 | 2,400万円 |
| 10年後 | 50歳 | 15年 | 1,800万円 |
| 15年後 | 55歳 | 10年 | 1,200万円 |
| 20年後 | 60歳 | 5年 | 600万円 |
| 満了直前 | 64歳 | 2年（最低保証） | 240万円 |

※最低支払保証期間2年のため、64歳以降に万一の場合でも最低24ヶ月分（240万円）は保証

```

```

## Ⅱ型の特徴

- **Ⅰ型**: 死亡・高度障害のみ保障
- **Ⅱ型**: 死亡・高度障害に加え、特定障害・要介護状態も保障対象

### Ⅱ型で追加される保障

| 保障項目 | 内容 |
|---------|------|
| 特定障害年金 | 所定の障害状態に該当した場合 |
| 介護年金 | 所定の要介護状態に該当した場合 |

---

## 付帯特約

### リビング・ニーズ特約（リビング・ベネフィット）
- 余命6ヶ月以内と判断された場合、死亡保険金の前払いを請求可能
- 特約保険料: 無料

---

## 評価まとめ

### メリット

- ✅ 優良体・非喫煙者割引で保険料を抑制
- ✅ Ⅱ型で障害・介護状態もカバー
- ✅ 最低支払保証期間2年で保険期間終了直前でも最低240万円保証
- ✅ リビング・ニーズ特約付き（無料）

### デメリット・注意点

- ⚠️ 完全掛け捨て型（解約返戻金ゼロ）
- ⚠️ 65歳以降は保障がなくなる
- ⚠️ 年齢が上がるほど受取総額は減少
- ⚠️ 高度障害療養加算がない（プルデンシャルとの違い）

### 適している人

- 死亡だけでなく障害・介護状態もカバーしたい方
- 子どもの教育費や住宅ローンが残っている方
- 万一の際、遺族に毎月の生活費を残したい方
- 65歳以降は年金や貯蓄で生活できる見込みの方
