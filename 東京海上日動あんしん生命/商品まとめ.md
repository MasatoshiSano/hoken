### 5疾病とは

1. がん（悪性新生物）
2. 急性心筋梗塞
3. 脳卒中
4. 肝硬変
5. 慢性腎不全

| **非喫煙者標準体** | ✗ | 基準外 | 安い |
| **喫煙者優良体** | ✓ | 良好 | やや高い |
| **喫煙者標準体** | ✓ | 基準外 | 高い |

| 項目 | 基準 |
|------|------|

| **喫煙** | 過去1年以内に喫煙なし |

## 3. メディカルKit R（還付型医療保険）

### 基本情報

| 項目 | 内容 |
|------|------|
| **商品名** | メディカルKit R |
| **保険期間** | 終身 |
| **払込期間** | 終身 |
| **健康還付給付金** | 所定年齢で払込保険料が戻る |

### 健康還付給付金（リターン）の仕組み

```
払込保険料 − 受取給付金 = 健康還付給付金
```

| ケース | 還付額 |
|--------|--------|
| 入院・手術なし | **払込保険料全額** |
| 給付金100万円受取済み | 払込保険料 − 100万円 |

### 特徴

| 特徴 | 内容 |
|------|------|
| ✅ **保険料が戻る** | 所定年齢で払込保険料が還付 |
| ✅ **還付後も保障継続** | 保険料は加入時のまま |
| ✅ **終身保障** | 一生涯の医療保障 |

### 注意点

| 注意点 | 内容 |
|--------|------|
| ⚠️ **保険料はやや高め** | 還付があるため |
| ⚠️ **特約保険料は還付対象外** | 主契約のみ対象 |

| **タイプ** | 引受基準緩和型 |

持病がある方でも、以下の3つの告知項目に該当しなければ加入可能：

1. 過去2年以内の入院・手術
2. 過去5年以内のがん・肝硬変等
3. 現在の要介護状態等
