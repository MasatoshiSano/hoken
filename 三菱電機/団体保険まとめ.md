# 三菱電機グループ 団体保険まとめ

> **状況：未加入。2026年9月時点でソニー生命のみ実加入。三菱電機団体保険は今後検討予定。**

## 概要

三菱電機グループ会社の従業員向け団体保険（2025年版/2026年）。
団体割引が適用されるため、個人で加入するより保険料が割安。

**被保険者:** 佐野 雅俊 様

---

## 保険の種類一覧

| 保険種類 | 保障内容 | 特徴 |
|---------|---------|------|
| **いのちの保険** | 死亡・高度障害 | がん補償付き |
| **病気・ケガの保険** | 入院・手術・通院 | 医療保障 |
| **がんの補償** | がん診断・治療 | がん特化 |
| **介護補償** | 介護一時金・費用 | 介護保障 |
| **所得補償** | 就業不能時の収入 | 働けない時の保障 |
| **自転車補償** | 自転車事故 | 賠償・傷害 |
| **賠償責任** | 日常生活賠償 | 個人賠償 |
| **ホールインワン** | ゴルフ補償 | 達成費用 |

**★★★★★（必須級）**

## 5. 所得補償保険

### 基本情報

| 項目 | 内容 |
|------|------|
| **正式名称** | 団体長期障害所得補償保険（GLTD） |
| **保障期間** | 1年更新 |
| **特徴** | 病気・ケガで働けなくなった時の収入を補償 |

### 保障内容詳細

| 項目 | 内容 |
|------|------|
| **補償対象** | 病気・ケガによる就業不能 |

| **支払期間** | 最長2年間 |
| **免責期間** | 7日間（就業不能開始から7日間は対象外） |
| **支払条件** | 医師の診断により就業不能と認められた場合 |

### 保険料例（月額・補償額別）

**補償月額10万円の場合：**

| 年齢 | 月額保険料 |
|-----|-----------|
| 35-39歳 | 約830円 |
| 40-44歳 | 約870円 |
| 45-49歳 | 約1,310円 |
| 50-54歳 | 約1,850円 |

**補償月額20万円の場合：**

| 年齢 | 月額保険料 |
|-----|-----------|
| 40-44歳 | 約1,740円 |
| 45-49歳 | 約2,620円 |

### 給付例

**例：病気で6ヶ月間就業不能になった場合（補償月額10万円）**

| 項目 | 計算 |
|------|------|
| 免責期間 | 最初の7日間は対象外 |
| 支払対象期間 | 6ヶ月 - 7日 ≒ 約5ヶ月半 |
| 受取総額 | 約55万円 |

### ポイント

- ✅ 傷病手当金（給与の2/3）を補完できる
- ✅ 住宅ローン返済中の方に有効
- ✅ 自営業者的なリスク対策
- ⚠️ 支払期間が最長2年（長期療養には不十分な場合も）
- ⚠️ 精神疾患は対象外の場合あり（要確認）
- ⚠️ 復職したら支払い停止

### おすすめ度

**★★★☆☆（状況による）**
- 住宅ローンがある方や扶養家族が多い方は検討価値あり
- 会社の傷病手当金制度と合わせて検討

| **保障期間** | 1年更新 |
| **特徴** | 自転車事故の傷害補償＋賠償責任をセットでカバー |

### 保障内容詳細

| 保障項目 | 金額 | 説明 |
|---------|------|------|
| **傷害死亡保険金** | 290万円 | 自転車事故で死亡した場合 |
| **傷害後遺障害保険金** | 最大290万円 | 後遺障害等級に応じて支払い |
| **傷害入院日額** | 6,000円 | 自転車事故によるケガで入院 |
| **傷害通院日額** | 3,000円 | 自転車事故によるケガで通院 |
| **個人賠償責任** | 最大3億円 | 他人にケガをさせた・物を壊した場合 |
| **示談交渉サービス** | あり | 保険会社が示談交渉を代行 |

### 保険料（月額）

| プラン | 月額保険料 | 対象者 |
|--------|-----------|--------|
| **本人型** | 約290円 | 被保険者本人のみ |
| **家族型** | 約500円 | 配偶者・子供も補償対象 |

### 補償される場面

| シーン | 補償 |
|--------|------|
| 自転車で転倒してケガをした | 傷害補償 |
| 自転車で他人にぶつかってケガをさせた | 賠償責任 |
| 自転車で車にぶつかって傷をつけた | 賠償責任 |
| 通勤中の自転車事故 | 傷害補償＋賠償責任 |

### ポイント

- ✅ 自転車事故による高額賠償に対応（最大3億円）
- ✅ 示談交渉サービス付きで安心
- ✅ 自転車通勤・通学をする方に必須
- ⚠️ 自転車以外の事故は対象外
- ⚠️ 家庭賠償責任保険と補償が重複する可能性あり

### おすすめ度

**★★★★☆（自転車利用者は必須）**
- 自転車通勤・通学をする方は必ず加入
- 家庭賠償責任保険に加入済みなら、傷害補償のみの保険を選ぶ方法も

## 7. 家庭賠償責任保険（個人賠償責任保険）

### 基本情報

| 項目 | 内容 |
|------|------|
| **正式名称** | 団体総合生活保険（個人賠償責任補償） |
| **保障期間** | 1年更新 |
| **特徴** | 日常生活のあらゆる賠償事故をカバー、**超低価格** |

### 保障内容詳細

| 保障項目 | 金額 | 説明 |
|---------|------|------|
| **個人賠償責任** | 最大3億円 | 他人への賠償責任を補償 |
| **示談交渉サービス** | あり | 保険会社が示談交渉を代行 |

### 保険料（月額）

| プラン | 月額保険料 | 対象者 |
|--------|-----------|--------|
| **本人型** | **約90円** | 被保険者本人のみ |
| **家族型** | **約170円** | 配偶者・同居親族・別居の未婚の子も補償 |

### 補償される場面（例）

| シーン | 補償対象 |
|--------|----------|
| **自転車事故**で他人にケガをさせた | ✅ 対象 |
| **買い物中**に商品を壊した | ✅ 対象 |
| **子供**が友達にケガをさせた | ✅ 対象（家族型） |
| **ペット**が他人を噛んだ | ✅ 対象 |
| **マンション**で水漏れを起こして階下に被害 | ✅ 対象 |
| **ゴルフ**で他人にボールを当てた | ✅ 対象 |
| **スキー・スノボ**で他人と衝突 | ✅ 対象 |

### 補償されない場面（例）

| シーン | 対象外理由 |
|--------|-----------|
| 仕事中の事故 | 業務上の賠償は対象外 |
| 故意による損害 | 故意は免責 |
| 同居の家族への賠償 | 家族間は対象外 |
| 自動車事故 | 自動車保険でカバー |

### ポイント

- ✅ **月額わずか90円**で最大3億円の賠償責任をカバー
- ✅ 示談交渉サービス付きで精神的負担を軽減
- ✅ 日常生活のほぼすべての賠償リスクに対応
- ✅ 家族型なら子供の賠償事故もカバー
- ⚠️ 1年更新のため毎年更新が必要
- ⚠️ 業務上の事故は対象外

### おすすめ度

**★★★★★（必須級 - 絶対加入すべき）**
- **月額90円で3億円の賠償責任**はコスパ最強
- 自転車保険の義務化にも対応
- 家族がいる場合は家族型（170円）を選択
- 火災保険や自動車保険に個人賠償が付いている場合は重複確認

## 団体保険のメリット・デメリット

### メリット

- ✅ **保険料が割安** - 団体割引で個人契約より安い
- ✅ **配当金還元** - 保険料の一部が戻ってくる可能性
- ✅ **加入しやすい** - 健康告知が簡易
- ✅ **給与天引き** - 支払いが楽
- ✅ **保険料控除対象** - 生命保険料控除が使える

### デメリット

- ⚠️ **1年更新** - 毎年更新で保険料が上がる可能性
- ⚠️ **退職時に継続不可の場合あり** - 会社を辞めると保障がなくなる可能性
- ⚠️ **終身保障ではない** - 一生涯の保障ではない
- ⚠️ **保障内容が固定的** - カスタマイズしにくい
